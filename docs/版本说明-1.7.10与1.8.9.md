OpenSlinky 源码 —— 同时支持 Minecraft 1.7.10 与 1.8.9
=====================================================

重要：这是一份源码，不是两份。

版本不是编译期决定的，是运行时检测的。看 src/engine/gui/classfile_constants.cpp
和 include/slinky/jids.h：

    int variant;   // 0x0 非零 = 使用替代映射
    int names;     // 0x4 0 = obfuscated, 1 = MCP, 2 = SRG

DLL 启动时读游戏里几个已知类，判断出这是哪个版本、用哪套映射，然后从 jids 表里
取对应的字段/方法 ID。所以：

    SlinkyNative.dll   -> 1.7.10 和 1.8.9 通用
    Slinky.exe         -> 两个版本通用

两版方法签名不同的地方，在 hook_tables.inc 里同时注册了两个钩子名，例如：

    {"postWorldClear_1_7", "(I)V",                          hook_post_world_clear_1_7}
    {"postWorldClear_1_8", "(I)V",                          hook_post_world_clear_1_8}
    {"setBlock_1_7",       "(Ljava/lang/Object;III...II)Z", hook_set_block_1_7}
    {"setBlock_1_8",       "(Ljava/lang/Object;Ljava/lang/Object;Ljava/lang/Object;I)Z",
                                                            hook_set_block_1_8}
    {"sendPacket_1_7",     "(Ljava/lang/Object;Ljava/lang/Object;Ljava/lang/Object;)V",
                                                            hook_send_packet_1_7}
    {"sendPacket_1_8",     "(Ljava/lang/Object;Ljava/lang/Object;)V", hook_send_packet_1_8}

安装钩子时按检测出的版本选一组。

目录
----

    src/data/             数据段（字符串表、字体、导入表、模块描述符）
    src/engine/base/      引擎入口、帧循环
    src/engine/gui/       ClickGUI（布局、卡片、毛玻璃、弹窗、控件）
    src/engine/jni/       JNI 层（ID 表、accessor、钩子安装、模块管理）
    src/engine/math/      数学与设置存储
    src/engine/modlib/    共享逻辑（方块表、背包、好友）
    src/engine/protected/ 受保护区域（钩子表）
    src/logic/            模块（combat / move / visual / block / utility / movement）
    src/platform/         平台层（NanoVG 绑定、GL 槽位、Windows CRT）
    injector/             注入器（Slinky.exe）
    include/slinky/       公共头文件
    third_party/          NanoVG、精简 CRT、GL 头

构建
----

需要 MSVC 2022 BuildTools + LLVM clang-cl + CMake + Ninja。

    set INCLUDE=<msvc>\include;<sdk>\Include\<ver>\ucrt;<sdk>\Include\<ver>\um;<sdk>\Include\<ver>\shared
    set LIB=<msvc>\lib\x64;<sdk>\Lib\<ver>\ucrt\x64;<sdk>\Lib\<ver>\um\x64
    cmake -S . -B build -G Ninja
    cmake --build build

产物 build/SlinkyNative.dll。注入器要单独重链（DLL 以 RCDATA 200 内嵌在 exe 里），
详见 DEVELOPMENT.md。

视觉相关
--------

这一版要改视觉，重点在这几个文件：

    src/engine/gui/gui_frosted.cpp      毛玻璃捕获、模糊、色调
    src/engine/gui/gui_layout.cpp       draw_rect_rounded / draw_rect_filled（材质原语）
    src/engine/gui/gui_cards.cpp        卡片尺寸、透明度
    src/engine/gui/gui_popups.cpp       弹窗
    src/logic/visual/notifications.cpp  通知条

毛玻璃当前参数（已写进代码默认值）：
    Opacity 30 / tint 10 / Blur 4 / Hue 220 / Panel frost 100

五个都是运行时可调滑块，在 GUI 模块设置页。调结构之前先看
"毛玻璃参考-2026-11-14.md" 里的材质规范。
